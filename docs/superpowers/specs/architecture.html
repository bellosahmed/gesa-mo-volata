Shamba Planner — system architecture

An offline whole-plot planning agent for African smallholders. A tiny language model handles understanding; deterministic tools own every number. Runs entirely on a $200 laptop, no internet.

plan ⇄ observe
Agent
orchestrator

Capped ReAct loop

Reads the request, plans, calls tools in sequence, observes results, decides the next step. Hard-limited to 3–4 steps and a fixed context window.

◆ Grammar guard

GBNF grammar forces every tool call to be valid JSON. The tiny model cannot emit a malformed call — this is what makes an agent loop survivable on a 3B model.

Why this is the best architecture

The judging formula quietly rewards a specific shape of system. This one is built backwards from it.

S = 0.50 · Accuracy + 0.30 · Speed + 0.20 · Efficiency − Thermal   (+15% local language, +10% budget profile)
50% Accuracy

Correctness is offloaded to code

Spacing, fertilizer splits and planting windows come from deterministic tools, not a 3B model guessing. Your biggest score is near-guaranteed — the failure mode that sinks Math, Healthcare and Creative entries is designed out.

30% Speed

Small model, short hops

A ~2 GB Q4 model on CPU plus a capped loop means few passes and short contexts. The reason the pure “Autonomous Agents” track loses here — runaway multi-step loops — is bounded on purpose.

20% Efficiency

Lives inside 7 GB, stays cool

Fixed context window + depth cap keep peak RAM and heat predictable, protecting against the instant-disqualify OOM and the thermal penalty. The benchmark harness proves it under emulation.

+25% Bonuses

Both bonuses are the product

The pluggable locale layer earns +15% local language; planning around scarce, affordable inputs is the +10% budget profile. Four orchestrated tools give the cross-disciplinary Best Integration story.

The one idea underneath all of it

Everyone else will ship a farming chatbot and gamble the 50% accuracy score on a tiny model’s knowledge. We ship an agent that thinks in language but calculates in code — so the model only does what small models are good at, and the rubric’s math stays on our side. Offline isn’t a rule we tolerate; for a rural farmer with no signal, it’s the entire point.
